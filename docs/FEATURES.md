# Planet Zoo 2 Zoo Planner — feature reference

Habitat groups, project notes, and park profiles form the core of Planet Zoo 2 Zoo Planner. Related configuration is grouped by task rather than collected in an undifferentiated list.

| Section | Description |
|---|---|
| Habitat groups | A dedicated section for habitat groups and the configuration details associated with that area. |
| Project notes | A dedicated section for project notes and the configuration details associated with that area. |
| Park profiles | Related settings collected into named groups for a clearer configuration workflow. |

The project page follows the same section structure.
